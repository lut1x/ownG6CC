G6 Control 0.2.0 Portable — личная панель для GIGABYTE G6 MF

Запуск: G6ControlCenter.exe. Нужны права администратора для доступа к штатному драйверу.
.NET 8 x64 включён в EXE; отдельно устанавливать его не нужно.
Распакуй всю папку в постоянное место. Перед запуском заверши старую панель через «Выход».

Автозапуск: Охлаждение → Запуск приложения → «Запускать при входе в Windows».
По умолчанию выключен. При включении программа запускается в трее через 10 секунд после входа.
Используется личная задача Планировщика Windows с необходимыми правами, без сохранения пароля.
При автоматическом запуске повторный запрос администратора не появляется.
Выключение переключателя удаляет задачу. Перед переносом или удалением папки выключи автозапуск;
после переноса включи его заново из новой папки. Автозапуск работает и от АКБ.

При запуске и подключении кабеля включается Работа. При отключении — АКБ.
Работа: штатный Quiet, boost CPU выключен, максимум CPU 99%.
АКБ: штатный PowerSaving, boost выключен, максимум CPU 85%, низкая доступная частота экрана.
Игра: только от сети, штатный Performance, boost включён, максимум CPU 100%.
Работа и АКБ разрешают снижение CPU до 5%; Игра держит запрос производительности 100%.
Простой CPU разрешён во всех профилях. Предпочтение экономии энергии задаётся, если настройка поддерживается Windows.
Схемы Windows создаются отдельно. При нормальном выходе исходная схема и частота экрана восстанавливаются.
Клавиатура: синий / красный / зелёный по профилю. Проверка цвета — визуальная.

Крестик закрывает окно в трей. Для полного завершения выбери Выход.
Охладить: максимум вентиляторов на 60 секунд, затем штатный автомат.
Вернуть автомат: штатное охлаждение, заводская кривая после экспериментов в этой панели.
Редактор кривых: перетаскивай две средние точки; применение отдельно. На выходе возвращается автомат.
Кнопка «Заводские точки» только сбрасывает черновик редактора; для немедленного возврата используй «Вернуть автомат».

Порог заряда доступен, только если прошивка вернула допустимые значения.
«Повышать производительность при нагрузке» выключено по умолчанию. Учитывает CPU: >=80% 15 секунд включает Игру;
<25% 45 секунд возвращает Работу. Ручная Игра не отменяется из-за простоя.
Графическая нагрузка RTX пока не используется. История не записывается.

Нет принудительного отключения RTX, управления сторонними службами,
разгона/undervolt и изменения настроек сторонних программ.
Windows продолжает штатно управлять энергосбережением GPU.
С несколькими мониторами панель не переключает частоту экрана.
После аварийного завершения временные схемы Windows могут остаться; обычный выход их удаляет.

settings.json рядом с программой — настройки панели, без истории показателей.
Библиотеки в vendor извлечены из официального пакета GIGABYTE для личного использования.
Это закрытый компонент Clevo/Insyde, он не является исходным кодом нашей программы.
Установленный штатный драйвер AcpiBridge нужен для работы; на этом ноутбуке он уже есть.
Программа не устанавливает драйвер и не предназначена для других моделей ноутбуков.

Диагностика без записи: --diagnose --report путь.json
Предпросмотр без изменения настроек: --preview
