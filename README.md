# G6 Control Center

Личная утилита для GIGABYTE G6 MF: охлаждение, питание от АКБ/сети и мониторинг.

Текущая версия **0.2.0 Portable**: нативное Windows-приложение на C#/WPF, основанное на исследовании штатного интерфейса.

## Запуск

`dist/G6ControlCenter-0.2.0-portable-win-x64.zip` — автономная сборка со встроенным .NET. Распакуй всю папку, заверши старую панель через «Выход» и запусти `G6ControlCenter.exe`. Права администратора нужны штатному драйверу, который уже установлен на этом ноутбуке.

Автозапуск включается на вкладке «Охлаждение», в блоке «Запуск приложения». При входе в Windows панель запускается в трее через 10 секунд. По умолчанию автозапуск выключен. Перед переносом папки выключи его, затем включи из нового расположения.

«Работа» включается при запуске от сети и подключении зарядки; «АКБ» — при отключении. «Игра» доступна только от сети. Есть реальные датчики, управление CPU boost через отдельные схемы Windows, подсветка, частота экрана, кривые CPU/GPU, временное охлаждение, порог заряда и трей с компактной панелью.

Крестик скрывает окно в трей. «Выход» завершает программу, возвращает автоматическое охлаждение, исходную схему питания и частоту экрана. Исходная схема питания не редактируется. Порог заряда сохраняется в прошивке по выбору пользователя.

## Сборка

Локальный SDK находится в `.tools/dotnet`. `tools/Build-App.ps1 -Publish` собирает приложение в `dist/G6ControlCenter`. Сторонних NuGet-зависимостей у приложения нет. Расширенная аппаратная DLL берётся из ранее скачанного официального пакета; её SHA256 проверяется при запуске.

Для portable: `tools/Prepare-PortableRuntime.ps1`, затем `tools/Build-App.ps1 -Publish -Portable -OutputDirectory dist/G6ControlCenter-0.2.0-portable`. Первый шаг скачивает официальные пакеты .NET в локальный источник. Иконки воспроизводятся через `tools/Build-Icons.ps1`.

`tests/G6ControlCenter.Checks` — проверки переходов профилей, порогов автоматизации, декодирования датчиков и допустимых кривых без обращения к железу.
