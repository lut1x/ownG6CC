# Личная панель G6: принятые решения

## Профили

- Работа: тихо, меньше тепловыделения CPU, комфортная отзывчивость.
- Игра: только от сети, доступная штатная производительность и охлаждение.
- АКБ: автоматически при отключении кабеля, автономность без потери комфортной работы; минимизация потребления RTX безопасным способом.
- При подключении зарядки всегда включается Работа, а не предыдущий профиль.
- Игра на АКБ недоступна.
- Подсветка: Работа — синяя, Игра — красная, АКБ — зелёная.
- Частота экрана и CPU boost входят в профиль.

## Состав интерфейса

- Главная: режим, источник питания, температуры/обороты, батарея, быстрые действия.
- Охлаждение: отдельная вкладка внутри приложения, редактор кривых и плавность изменения оборотов.
- Временное максимальное охлаждение и возврат к автоматическому управлению.
- Компактный доступ из трея.
- Сведения батареи и лимит заряда, если аппаратная поддержка подтверждена.

## Исключено пользователем

- Правила по приложениям.
- Исторические графики, запись истории, сравнение сессий.
- Журнал экспериментов, таймер ручного профиля, отдельный режим наблюдения.
- Отдельный профиль Тихо: его задача входит в Работу.

## Ещё обсуждается

- Дополнительные сигналы нагрузки помимо CPU для автоматического повышения производительности. Текущая реализация: CPU ≥80% 15 с включает Игру, <25% 45 с возвращает Работу; только от сети, по умолчанию выключено.
- Способ уменьшения потребления RTX. Найден OEM-метод `SetNVIDIAPower(bool)`, делегирующий вспомогательному EXE команду `0x0013`; его конечное действие и совместимость ещё предстоит установить.
- Внешний вид выбран: Fluent с плотной компоновкой показателей из «Пульта». Охлаждение — вкладка. В 0.1 также есть отдельное компактное окно из трея.

## Реализовано в 0.1

Настоящие датчики, три профиля со схемами Windows и OEM-режимами, частота экрана, профильная подсветка, аппаратные кривые, максимальное охлаждение на 60 с, автомат, проверяемый порог заряда, трей и компактное окно. Истории показателей и правил по приложениям нет. Автоспорт пока только по CPU, выключен по умолчанию. RTX принудительно не отключается.

Удаление ненужных остатков штатной программы пользователь разрешил. Ещё не выполнено; необходимые новой панели аппаратные зависимости нужно сохранить.

## Правки интерфейса 0.1.1

- Удалены строка подключения контроллера, характеристики ноутбука внизу слева и блок текущего цвета подсветки на главной.
- Версия показывается только цифрами внизу слева. В заголовке окна версии нет.
- «Мегатихо» заменено на «Тихо».
- Переключатель автоматического профиля называется «Повышать производительность при нагрузке»; пороги не изменялись.
- Верхняя панель и кнопки окна встроены в дизайн приложения.
- Выбор зарядного порога переделан: тёмный фон, контрастные пункты и проценты в значениях.
- Пользователь подтвердил реальную работу переключения подсветки и редактора кривых.

## Portable 0.2.0

- Оригинальная эмблема вентилятора, отдельные иконки профилей, синий/красный/зелёный значок трея.
- Самодостаточная portable-сборка со встроенным .NET; настройки рядом с EXE. Штатный драйвер остаётся необходимым.
- Опциональный автозапуск в трее через 10 секунд после входа в Windows. Переключатель в блоке «Запуск приложения» на вкладке «Охлаждение».
- Задача Планировщика текущего пользователя, без сохранения пароля и повторного UAC при входе. Выключение удаляет собственную задачу. Изменение папки обнаруживается, предлагается перевключить автозапуск.
