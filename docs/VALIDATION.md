# Проверка G6 Control 0.1.0

31 октября 2026, GIGABYTE G6 MF, BIOS FB10, Windows x64.

## Выполнено

- Release-сборка и публикация: без ошибок и предупреждений.
- 23 проверки без железа: подключение/отключение сети, блокировка Игры на батарее, возврат в Работу при подключении, устойчивый порог и задержка Автоспорта, приоритет ручной Игры, форматы пакетов, порядок байт тахометров и отклонение недопустимых кривых.
- Диагностика реальных датчиков, батареи и экрана: успешно. Использован штатный драйвер; системные DLL/драйверы не заменялись.
- Профиль Работа: отдельная схема Windows создана, значения CPU записаны и прочитаны обратно, штатный профиль отправлен контроллеру. После проверки исходная схема восстановлена, временная схема удалена.
- В собственных схемах отдельно задаются минимальная/максимальная производительность CPU, режим boost и разрешённый простой; настройка энергоэффективности применяется при наличии поддержки. Исходная пользовательская схема не редактируется.
- Финальная сборка прошла цикл Работа → Игра → Работа от сети с чтением параметров Windows; по завершении проверки исходная схема возвращена. Отчёт: `research/app-validation/profiles.json`.
- Максимальное охлаждение: CPU примерно 2420 → 6574 RPM, GPU 2311 → 6023 RPM. После возврата в автомат отдельным чтением подтверждено снижение оборотов; мгновенно они не падают из-за инерции и регулировки.
- Зарядный порог: прошивка вернула допустимые стартовые и конечные значения. Проверена запись окна 70–80%, затем восстановлены исходные 95–100% с выключенным ограничением; обратное чтение совпало.
- Пользовательская кривая: проверена более интенсивная верхняя точка CPU/GPU 80%; новые температуры точек подтверждены пакетом 13. В конце восстановлены исходные точки и автоматическое управление.
- Интерфейс: открыты Главная, Охлаждение и компактное окно; сделаны снимки, проверены контраст и расположение элементов. Финальная проверка интерфейса не изменяет настройки ноутбука.

Основные отчёты: `research/app-validation/diagnostic.json`, `fan-check.json`, `after-fan-check.json`, `integration.json`. Изображения интерфейса находятся в той же папке.

## Пределы проверки

- Физическое отключение зарядки не выполнялось. Переходы АКБ/сеть проверены на уровне политики; реальное событие нужно посмотреть при использовании.
- Не проводились длительный нагрузочный тест, замер автономности или проверка сна/пробуждения на реальном цикле.
- В последующей обратной связи пользователь подтвердил переключение подсветки. Редактор кривых также оценён как работающий.
- Автоспорт 0.1 использует нагрузку CPU, без GPU-счётчиков и без правил по приложениям. По умолчанию выключен.
- Принудительное отключение RTX не реализовано. Панель не опрашивает NVIDIA API и не меняет приоритеты сторонних процессов или системных служб.
- Панель не гарантирует восстановление схем Windows после аварийного завершения. Кривые исполняются контроллером; программной ручной фиксации оборотов на низком уровне нет.
- «Вернуть автомат» восстанавливает заводские точки, считанные при запуске этой сессии; исходные duty-байты сохраняются без округления к процентам.
- Удаление остатков OEM-компонентов в этой версии не выполнялось: установленная библиотека и штатные драйверы нужны приложению.

## Portable 0.2.0

- Самодостаточная сборка win-x64, .NET Core/Desktop 8.0.33 внутри EXE, без обрезки WPF. Сборка без ошибок и предупреждений.
- Запуск интерфейса, чтение аппаратных данных и проверки автозапуска выполнены с DOTNET_ROOT, указывающим на пустую папку, и отключённым поиском глобальной среды .NET.
- Создание задачи, права, вход текущего пользователя, аргумент --tray, работа от батареи и удаление задачи проверены реальным обратным чтением. Предыдущее состояние автозапуска восстановлено; проверка не оставляет его включённым.
- Проверены скрытый старт с видимой иконкой трея и последующее открытие окна. Аппаратные записи при проверке интерфейса отключены.
- Новые оригинальные иконки приложения и профилей; иконки ICO содержат размеры 16–256 px. В интерфейсе выбирается наибольший кадр для чёткой эмблемы.
- Отчёты и изображения: `research/app-validation/0.2.0/`.
- Физическая перезагрузка Windows в рамках проверки не выполнялась.
